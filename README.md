# Menu Calculadora



## Descrição



Programa em Java que apresenta um menu de opções para realizar operações matemáticas básicas. O usuário pode escolher entre somar, subtrair, multiplicar, dividir ou sair do programa.



## Tecnologias utilizadas



- Java

- NetBeans

- Scanner



## Entrada



O usuário informa uma opção do menu e, quando necessário, dois números para realizar a operação escolhida.



## Saída



O programa exibe o resultado da operação matemática selecionada e permite realizar novas operações até que o usuário escolha a opção de saída.



## Estruturas utilizadas



- `do while`

- `switch case`

- `if`

- `Scanner`
